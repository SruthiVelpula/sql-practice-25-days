# 25-Day SQL Practice

Daily SQL practice to build data analyst skills, one topic per day.

| Day | Topic |
|---|---|
| 1 | SELECT, FROM, WHERE, ORDER BY, LIMIT |
| 2 | AND, OR, IN, BETWEEN, LIKE, DISTINCT |
| 3 | COUNT, SUM, AVG, MIN, MAX, COUNT(DISTINCT) |
| 4 | GROUP BY, HAVING |
| 5 | INNER JOIN, JOIN + GROUP BY, GROUP BY/HAVING review |
| 6 | INNER JOIN practice: JOIN + WHERE + GROUP BY + HAVING + ORDER BY |
| 7 | LEFT JOIN vs INNER JOIN, table order, NULLs, LEFT JOIN + WHERE + GROUP BY |
| 8 | LeetCode SQL 50 #1-6 (NULLs, >=, DISTINCT, CHAR_LENGTH, LEFT JOIN), LEFT JOIN + COUNT + GROUP BY |
| 9 | SELF JOIN (table aliases, worker/boss), LEFT self join, self join + GROUP BY, LeetCode #197 Rising Temperature (DATEDIFF) |
| 10 | CASE WHEN (labels with WHEN/THEN/ELSE/END), CASE + COUNT + GROUP BY |
| 11 | LeetCode SQL 50 #610 Triangle Judgement (CASE WHEN + AND), #620 Not Boring Movies (% for odd/even, ORDER BY DESC) |
| 12 | LeetCode SQL 50 #1075 Project Employees I, #1211 Queries Quality and Percentage (ROUND, AVG, math in SQL, % with CASE) |
| 13 | SUBQUERIES (one-value subquery in WHERE and in math), percentage pattern (part / whole * 100), LeetCode #1633 |
| 14 | LeetCode #570 (self join + HAVING COUNT), revision: IN, ORDER BY + LIMIT, INNER JOIN, GROUP BY + COUNT, CASE WHEN |

**Dataset:** sample `employees` (emp_id, name, dept, salary, city), `departments` (dept, manager, floor), `Staff` (staff_id, name, boss_id), and LeetCode `Users`/`Register` tables, plus LeetCode SQL 50 problems
**Tools:** SQLite (sqliteonline.com), LeetCode (MySQL)
