# 25-Day SQL Practice

Daily SQL practice to build data analyst skills, one topic per day.

| Day | Topic |
|---|---|
| 1 | SELECT, FROM, WHERE, ORDER BY, LIMIT |
| 2 | AND, OR, IN, BETWEEN, LIKE, DISTINCT |

**Dataset:** a sample `employees` table (emp_id, name, dept, salary, city)
**Tool:** SQLite (sqliteonline.com)
